# MarketArena

MarketArena — экономический и жизненный симулятор, где игрок начинает с обычной работы и постепенно строит капитал через карьеру, накопления и финансовый рынок.

## Текущий этап

**Phase 1 — Offline Game Foundation**

Сейчас реализован первый игровой маршрут:

**Регистрация → режим игры → выбор страны → сложность → игровой рабочий стол**

В офлайн-прототипе уже есть:
- профиль игрока без серверной регистрации;
- режим Offline как основной рабочий режим;
- Online отображается как будущий режим и пока недоступен;
- выбор страны через интерактивную атласную карту;
- обязательная страна **Словения**;
- Славория, Лирания, Дарваст, Эстравия и Саверния;
- профиль страны: столица, валюта, биржа, население, экономика;
- 60 публичных компаний: 12 на страну, с тикерами, секторами и CEO;
- три уровня сложности и стартовый капитал;
- игровой день;
- работа и подработки как источник капитала;
- биржа, компании, портфель, жизнь, карта и новости как реальные переключаемые разделы;
- первые учебные покупки активов.

## Игровая идея

Главный цикл:

**работа → доход → расходы → накопления → покупка активов → рост капитала → новые возможности**

Игрок не просто смотрит на котировки. Он живёт внутри экономики: выбирает профессию, принимает решения о времени, зарабатывает деньги и решает, когда и во что инвестировать.

## Карта

Карта строится как современный атлас:
- крупные материковые формы;
- моря и побережья;
- политические границы;
- столицы;
- горные системы;
- реки;
- торговые маршруты;
- экономические регионы.

География должна выглядеть серьёзно и правдоподобно, но не копировать карту Земли целиком. Государственные флаги создаются отдельно и не используют декоративные «магические» символы.

## Страны

| Страна | Столица | Валюта | Основные отрасли |
|---|---|---|---|
| Словения | Любляна | EUR | промышленность, фармацевтика, логистика |
| Славория | Велиград | SLD | промышленность, энергетика, финансы |
| Лирания | Элион | LRN | финансы, судоходство, страхование |
| Дарваст | Кадар | DVT | нефть, металлы, тяжёлая промышленность |
| Эстравия | Селена | EST | технологии, биотех, электроника |
| Саверния | Ривен | SVR | агро, логистика, потребительский сектор |

## План разработки

1. Довести карту до полноценного атласа и проработать границы.
2. Создать полный набор из 60 публичных компаний.
3. Создать CEO, советы директоров и истории компаний.
4. Развернуть полноценный рынок: котировки, стакан, заявки, отчётность.
5. Расширить жизнь игрока: жильё, расходы, образование, кредиты, профессии.
6. Добавить системные экономические события и цепочки поставок.
7. После полноценного Offline — серверный Online.

## Запуск

```bash
npm install
npm run dev
```

Web — основной клиент. Desktop/Steam позже используют тот же клиент. Online будет серверным, Offline — локальной песочницей.

## MarketArena 1.0.1

Текущий клиент остаётся offline-first и использует существующий React + Vite + TypeScript + Three.js стек. Игровое состояние сохраняется локально: профиль, страна, сложность, деньги, портфель, сделки, игровой день и активный раздел.

На рынке сейчас доступно **60 публичных компаний** — по 12 на каждую из пяти стран. Каждая компания имеет тикер, сектор, CEO, описание и детерминированную динамику котировки.

Раздел **Updates & Patch Notes** хранится в `src/App.tsx` в массиве `PATCH_NOTES`; новые версии можно добавлять одной записью без изменения UI.
