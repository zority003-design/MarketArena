# MarketArena

MarketArena — экономический и биржевой симулятор в вымышленном мире.

## Текущий этап

**Phase 0 — World & Visual Prototype**

На этом этапе мы фиксируем:
- визуальный язык игры;
- карту мира;
- страны, столицы и валюты;
- базовую структуру экономической вселенной;
- архитектуру будущего клиента.

## Визуальное направление

Гибрид современного экономического симулятора и профессионального финансового терминала:
- тёмная интерфейсная основа;
- светящиеся акцентные линии;
- минималистичная SVG-карта;
- плотная финансовая типографика;
- карточки компаний и стран;
- профессиональные графики без копирования конкретных существующих терминалов.

## Запуск

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес приложения.

## Архитектурный принцип

Клиент будет отделён от игровой экономики. В будущем браузерная и desktop/Steam-версии будут использовать один клиентский код и подключаться к серверной экономике MarketArena.
