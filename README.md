# MarketArena

MarketArena — экономический и биржевой симулятор в полностью вымышленном мире.

## Текущий этап

**Phase 0.5 — World Map & Visual Foundation**

Сейчас в прототипе:
- собственная вымышленная география;
- пять рабочих государств: Славория, Лирания, Дарваст, Эстравия и Саверния;
- столицы, валюты и фондовые биржи;
- первые концепты государственных флагов;
- рельеф, реки, порты и торговые маршруты на интерактивной SVG-карте;
- переключение Offline / Online;
- основа будущего интерфейса человека, рынка и экономики.

## Визуальное направление

Не фэнтези и не карта реального мира.

Цель:
- реалистичная картографическая логика;
- естественные границы и рельеф;
- сдержанная государственная символика;
- тёмный современный финансовый интерфейс;
- отдельные уровни интерфейса для новичка и профессионального трейдера.

## Запуск

```bash
npm install
npm run dev
```

## Архитектурный принцип

Web — основной клиент. Desktop/Steam позже используют тот же клиент. Онлайн-экономика будет серверной и авторитетной, Offline — локальной песочницей.
