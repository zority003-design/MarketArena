# MarketArena — Game Design Document v0.1

## 1. Vision

MarketArena — это экономический симулятор в полностью вымышленном мире. Игрок не просто торгует акциями: он строит финансовую жизнь внутри динамической экономики.

Ключевой принцип:

> Мир живёт независимо от игрока, а решения игрока становятся частью его истории.

## 2. Два режима

### Offline

Песочница:
- выбор страны;
- выбор стартового капитала;
- выбор сложности;
- управление скоростью времени;
- локальная экономическая история;
- возможность экспериментировать без общего сервера.

### Online

Общий мир:
- единое состояние рынка;
- одинаковые мировые события для всех игроков;
- ускоренное игровое время;
- стартовый капитал одинаков для всех игроков;
- глобальные рейтинги;
- сезоны и достижения.

## 3. Игровой цикл

Жизнь → доход → расходы → накопления → инвестиции → риск → капитал → новый уровень возможностей.

На рынке:

Новость → ожидания → заявки → сделки → цена → отчётность → новая информация.

На уровне мира:

Событие → отрасль → компании → валюты/ставки → рынки → поведение игроков.

## 4. Мир

Первый прототип содержит пять государств:
- Вельмира — технологии, финансы, машиностроение;
- Норвесса — энергетика, логистика, металлургия;
- Ардель — фармацевтика, биотехнологии, химия;
- Сольвен — потребительский сектор, туризм, агро;
- Таврен — добыча, автомобили, оборонная промышленность.

Это рабочие названия. Перед публичным релизом будет отдельная проверка названий.

## 5. Компании

Целевая структура первой полной версии:
- минимум 12 публичных компаний на страну;
- у каждой компании есть сектор, продукты, финансовые показатели, история, руководство, конкуренты и события;
- CEO — вымышленный персонаж с биографией, стилем управления и репутацией.

При пяти странах стартовая цель — 60 публичных компаний.

## 6. Финансовые инструменты

Базовый уровень:
- акции;
- дивиденды;
- простые графики;
- новости.

Продвинутый:
- отчётность;
- P/E, EPS, ROE, ROA;
- объёмы;
- волатильность;
- стакан;
- limit/market/stop orders.

Профессиональный:
- short;
- margin;
- futures;
- options;
- hedging;
- сложные стратегии.

## 7. Экономика

Модель должна связывать:
- инфляцию;
- процентные ставки;
- занятость;
- потребление;
- сырьевые цены;
- торговлю;
- государственные решения;
- отраслевые циклы;
- корпоративные результаты.

## 8. IP-принцип

Все государства, компании, персонажи, логотипы, тексты, события, карта и визуальные материалы создаются для MarketArena с нуля.

Не использовать реальные бренды, реальные котировки или чужие игровые ассеты без отдельного разрешения/лицензии.

Название MarketArena пока считается рабочим и требует отдельной trademark clearance-проверки.

## 9. Платформы

Целевой принцип:
- Web — основной клиент;
- Desktop — тот же клиент в отдельной оболочке;
- Steam — отдельная дистрибуция desktop-клиента;
- Online-экономика — серверная;
- Offline — локальная песочница.
